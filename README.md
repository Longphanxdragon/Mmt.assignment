# AsynapRous (CO3094) — Local Dev Guide

This project is a small TCP-based HTTP/proxy framework used for learning proxy/backend routing.

Contents
- `CO3094-asynaprous/` — packaged source (preferred)
- `CO3094-asynaprous/daemon/` — core server code: `backend.py`, `proxy.py`, `httpadapter.py`, `request.py`, `response.py`, `dictionary.py`
- `CO3094-asynaprous/apps/` — sample app (`sampleapp.py`)
- `CO3094-asynaprous/config/proxy.conf` — host → backend mapping

Prerequisites
- Python 3.8+ (tested on 3.12)

Quick start (local)
1. Clone and enter repository:

```bash
git clone https://github.com/Longphanxdragon/Mmt.assignment.git
cd Mmt.assignment
```

2. (Optional) Create virtualenv:

```bash
python3 -m venv venv
source venv/bin/activate
```

3. Check syntax (catch parse errors early):

```bash
python3 -m py_compile CO3094-asynaprous/daemon/*.py CO3094-asynaprous/apps/*.py CO3094-asynaprous/start_*.py
```

4. Ensure `CO3094-asynaprous/config/proxy.conf` points to `127.0.0.1` for local testing.

5. Start development servers (helper script):

```bash
./run-dev.sh
```

6. Test via curl (proxy forwards based on Host header):

```bash
curl -i --max-time 10 -X GET http://127.0.0.1:8080/get-list -H 'Host: localhost:8080'
```

Stopping servers:

```bash
./stop-dev.sh
```

Common pitfalls & quick fixes
- `IndentationError`: open indicated file, fix indentation in the block (Python requires consistent spaces/tabs).
- `SyntaxError: '{' was never closed`: check dictionary or multi-line literal and add the missing `}`.
- `ImportError: MutableMapping`: change `from collections import MutableMapping` to `from collections.abc import MutableMapping`.
- `AttributeError: 'NoneType' object has no attribute 'get'` in `request.py`: ensure headers are parsed before reading cookies.
- `Connection refused` from proxy: ensure `proxy.conf` points to reachable backend IP/port.

Debugging checklist
- `python3 -m py_compile ...` to catch syntax errors.
- Run backend and proxy in separate terminals to view logs.
- Use `ss -ltnp | grep ':8080\\|:9000'` or `lsof -iTCP:8080 -sTCP:LISTEN -n -P` to find processes occupying ports.
- Kill stale PIDs and restart.

If you want, the repository includes `run-dev.sh` and `stop-dev.sh` to start/stop services locally and logs are written to `/logs/`.
